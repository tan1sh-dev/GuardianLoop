Platform features

Every stage of the
vulnerability lifecycle.

From a single file upload to a full GitHub PR scan — GuardianLoop handles the entire security review lifecycle without manual intervention.

Multi-mode Ingress
Upload a file, paste code directly, point to a GitHub Pull Request URL, or use the built-in demo. GuardianLoop handles Python (.py) and C/C++ (.c, .cpp) source files up to 1 MB.
SAST-powered Scanning
Scout runs both Semgrep (with custom + registry rules) and Bandit against your code. Findings are emitted as structured Finding objects for the pipeline to consume.
CVE & CVSS Classification
Each finding is enriched with real CVE identifiers and CVSS 3.1 scores pulled from the NVD API. You see exactly how severe each weakness is, with exploitability context.
AI-powered Patching
The Fixer agent uses Gemini 2.5 Pro with chain-of-thought prompting (k=5 reasoning steps). It produces a diff patch and a transparent audit trail of its reasoning chain.
Red-Team Sandbox Verification
Every patch is verified by running the original exploit against the patched code inside a hardened Docker container — network-isolated, read-only, memory-capped at 512 MB.
Live Security Console
Watch scans run in real time via the dashboard. See the GuardianLoop pipeline progress agent-by-agent, stream structlog output live, and open the full report when complete.
The pipeline

Five agents.
One shared state.

Built as an autonomous pipeline with a single Pydantic PipelineState object that flows through every node. Each agent is async, testable, and independently mockable.

01
Scout
semgrep 1.62 · bandit 1.7.5
Runs Semgrep with the full custom + community ruleset alongside Bandit for Python-specific checks. Emits structured Finding objects with file, line, rule ID, snippet, and CWE tag.
02
Classifier
NVD API · gemini-2.5-flash (optional LLM path)
Maps each CWE to real-world CVE records from the National Vulnerability Database. Enriches findings with CVSS 3.1 severity scores, attack vectors, and exploitability summaries.
03
Fixer
gemini-2.5-pro · chain-of-thought k=5
Uses Gemini 2.5 Pro with chain-of-thought prompting. Produces a unified diff patch and a multi-step reasoning chain that feeds the pedagogical audit report. Falls back to Gemini 2.5 Flash on failure.
04
Red-Team
docker sandbox · semgrep fallback
Runs the original exploit input against the patched code in an isolated container (--network=none --read-only --memory=512m). On failure, loops back to Fixer for up to 3 iterations.
05
Report
JSON + Markdown writers
Terminal node that writes the complete run artifacts: run_summary.json, enriched_findings.json, patches.json, verifications.json, and a structured report.md with What / Why / How sections for every finding. All downloadable from the dashboard.
Why GuardianLoop

Not just a scanner.
A closed-loop system.

Traditional SAST tools flag issues and leave the rest to you. GuardianLoop closes the loop — it patches, verifies, and explains, end to end.

Traditional SAST
Finds vulnerabilities, stops there
Tools like standalone Semgrep or Bandit give you a list of findings with line numbers. No CVE context, no fix, no verification — security engineers spend hours triaging and manually patching.
GuardianLoop
Finds, enriches, patches, and verifies
The four-agent pipeline produces a verified, sandbox-tested patch alongside a transparent AI reasoning chain — in under a minute. Nothing to triage, nothing to manually fix.
AI Code Assistants
Suggest fixes without verification
LLM-based code assistants can produce plausible-looking patches that still fail under adversarial input. There's no automated adversarial check to confirm the exploit is actually blocked.
GuardianLoop
Red-team verifies every patch in a sandbox
The Red-Team agent reruns the exact exploit inside a hardened Docker container against the patched code. Only patches that demonstrably block the attack are accepted. Failed patches trigger a Fixer retry loop.
Black-box pipelines
You don't know why the fix works
Automated tools rarely explain reasoning. When a patch is produced, developers have no insight into the taint flow analysis or why the specific change resolves the weakness class.
GuardianLoop
Full chain-of-thought audit trail
Every patch includes a multi-step CoT reasoning chain from Gemini 2.5 Pro that explains the taint flow, the fix strategy, and why the patch preserves semantics. Rendered as a readable What / Why / How report.
